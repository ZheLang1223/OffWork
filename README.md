# 下班了

一个记录上下班时间、查看月度工时的 Windows 小工具。数据保存在本机，无需账号、网络服务或 Excel 软件。

## 安装

1. 在本仓库的 [Releases 页面](https://github.com/ZheLang1223/OffWork/releases)下载 `OffWork-Setup.exe`。当前测试版为 `v1.0.0-beta.2`。
2. 双击安装，可选择创建桌面快捷方式。
3. 从开始菜单或桌面启动“下班了”。

支持 Windows 10、11，需要 .NET Framework 4.8 或更高版本。较新的 Windows 10 和 Windows 11 已自带；缺少时，安装程序会提示打开微软下载页面。普通用户无需安装 .NET SDK 或 .NET 10 Desktop Runtime。

程序安装到 `%LOCALAPPDATA%\Programs\下班了`，无需管理员权限。

## 使用

- **打卡**：点击整张上班或下班卡片，记录当前时间。
- **更新时间**：已有时间时，点击卡片会显示红色“确认”。10 秒内再次点击，才会替换为当前时间；超时或失去焦点后取消确认。
- **直接改时间**：右键点击卡片，或用左右方向键选择卡片后按 F2，在原位置输入 `09:00` 或 `0900`。回车或点击空白处保存，Esc 取消；留空保存可清除该时间。无效时间会提示错误并保留编辑状态。
- **补录或编辑日期**：点击日历中的日期，可修改上下班时间、出勤类型和备注，也可删除当天记录。
  时间支持 `10:11`、`9:00`、`9：05` 和四位数字（`1011` → `10:11`，`0100` → `01:00`）；留空表示未打卡。
- **查看统计**：切换月份查看工时、剩余目标和工作日。进度状态表示相对于当前日期的计划进度。
  达到月目标后进度条变绿，超额部分以橙色覆盖显示，条下显示超额工时和实际完成比例；橙色最多覆盖整条，比例和工时仍显示实际数值。四张统计卡片支持鼠标悬浮高亮。
- **修改设置**：点击右上角齿轮，设置每日目标工时和标准上下班时间。标准时间仅保存设置，不会自动打卡。

关闭窗口或最小化后，程序继续在系统托盘运行。点击托盘图标或右键选择“打开程序”恢复窗口；右键菜单也可选择“上班打卡”“下班打卡”或“退出”。窗口不支持手动调整大小，小屏幕下自动调整布局并提供滚动。

程序只运行一个实例。重复打开程序会唤起已有窗口，包括已最小化或隐藏到托盘的窗口。

后台每 10 分钟检查日期变化，恢复窗口和打卡前也会检查。跨天后刷新今日记录；日历原先选中当天时跟随切换，查看历史日期时保留选择。前一天缺失的下班时间需自行补录。

日历按内置节假日规则计算工作日；内置规则可能不覆盖其他年份或你的排班，请按实际情况调整出勤类型。

## 数据和卸载

默认数据目录是“文档\下班了”。如果在已有 `工时记录.xlsx` 的自定义目录直接运行程序，会使用该目录。可在设置中打开当前数据目录。

| 文件或目录 | 内容 |
| --- | --- |
| `工时记录.xlsx` | 工时记录与设置 |
| `backups` | 保存前生成的工时表备份 |
| `待同步.json` | 等待写入工时表的记录，存在时请一并保留 |
| `holidays.json` | 可选的自定义节假日规则 |

备份时复制整个数据目录。避免同时运行多个程序实例或在外部软件中同时编辑工时表。

可从 Windows“设置 → 应用”卸载。卸载不会删除工时数据；删除桌面快捷方式后，仍可从开始菜单启动。

## 构建

开发者需要安装 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) 和 [Inno Setup 6](https://jrsoftware.org/isinfo.php)。

退出正在运行的程序，然后双击根目录的 `build.cmd`。首次构建需要联网下载编译依赖。构建成功后：

- 根目录的 `下班了.exe` 和 `下班了.exe.config` 更新，可直接运行，两个文件需放在一起。
- `dist\下班了-Setup.exe` 是本地安装包；发布到 GitHub Releases 时使用名称 `OffWork-Setup.exe`。

源码、图标和打包配置位于 `src`；`src\bin`、`src\obj` 是可删除的构建缓存。程序使用 .NET Framework 4.8，不随安装包打包整个运行时。
